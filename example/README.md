# scroll_transition example

A catalogue app with one demo per `scroll_transition` feature: fade and
scale, 3D drum, blur and desaturate grid, VisualEffect carousel (LTR/RTL),
PageView, reversed chat, the animated configuration, builder mode, a pinned
header with `topInset`, nested rows with keep-alive, and a live geometry
readout.

```sh
flutter run -d chrome   # or macos, android, ios
flutter test            # opens and scrolls every demo
```
